## Delivered interface

- [Shared CSS](../static/css/app.css) provides fluid aligned page/header gutters, adaptive filter/catalog/form grids, consistent fields/buttons/tables, tonal surfaces, shared elevation and spring/shape feedback. Reduced-motion preferences suppress transitions. Form controls/buttons have 48px minimum height; text areas are resizable from a shared 8rem size.
- [Theme generator](../scripts/build-theme.mjs), [package scripts](../package.json) and [lockfile](../package-lock.json) add pinned `@material/material-color-utilities` 0.4.0 (Apache-2.0), with no transitive additions or unrelated version changes. The existing esbuild resolves its published imports for a Node-only build helper. A light `SchemeTonalSpot` palette derives primary/secondary/tertiary, neutral/surface and error/on/container roles from campus seed `#047857`. Nine text-role pairs must meet 4.5:1 or the build fails. Colors are generated at build time; no OS wallpaper access, per-account appearance preferences or browser color-library runtime is added.
- [Base](../templates/base.html) loads generated `theme.css` before `app.css`; [workspace](../templates/components/workspace.html), navigation/account menu, authentication intro and action-link components unify existing pages. [Compact navigation script](../static/js/workspace-navigation.js) reveals the active destination; native account-menu/Escape and POST/CSRF logout remain in use. Home shortcuts now point to existing features rather than describing delivered modules as pending.
- Existing account/inventory/borrowing/operations forms change widget classes only. Field names/IDs, allowlists, validation, authorization and workflow services are preserved. Templates use consistent action emphasis, two-column edit forms from 840px, a 1:2 request-details/items split from 1280px and local keyboard-focusable table scrolling. A positioned table header fixes the mobile overflow caused by an unanchored visually hidden label; duplicate purpose-error markup was removed.
- Build/dependency disclosure, current readiness, [canonical styling rules](../docs/coding-standards.md#shared-m3-roles-and-components-ui-09), [DEV setup](../DEV.md#frontend-assets-tailwind-and-page-scripts) and [Module 14 manual cases](../docs/manual-test-guide.md#module-14--shared-m3-layout-and-controls-ui-09) are updated.
